# Salle de sport (HTML / CSS / JS / PHP / MySQL)

1. Copier le dossier dans `htdocs` (XAMPP) ou `www` (WAMP).
2. Importer `sql/database.sql` dans phpMyAdmin.
3. Adapter l'accès MySQL dans `includes/db.php` si besoin.
4. Ajouter vos photos dans `assets/img/` (one-arm-row.jpg, lat-pulldown.jpg).
5. Ouvrir http://localhost/salle-sport/
